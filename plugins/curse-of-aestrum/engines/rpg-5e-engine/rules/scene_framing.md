## Overview

The display-**mode** layer over Aria's neutral
[scene_framing.md]({{PLUGIN_ROOT}}/engines/story-engine/rules/scene_framing.md), which owns the
genre-agnostic core: player-driven pacing, the explicit transition marker,
split-cast alternation, fade-to-black on mutual consent, in-fiction clock
advance, setting-imposed non-consent cuts, cutaways, and travel framing.

**Read Aria's file first.** Everything structural in scene framing is
mode-independent and lives in Aria. This file adds only how the player's
display mode interacts with it.

---

## Mode Interaction — Tone, Not Structure

The scene transition marker, the natural-breakpoint cuts, the fade-to-black
mechanics, and the clock-advance defaults are **mode-independent** — shared
scene-management norms that need the same shape for every player.

What varies by mode (see
[information_disclosure.md]({{PLUGIN_ROOT}}/engines/rpg-5e-engine/rules/information_disclosure.md#scene-density--novel-vs-game-modes))
is the prose that **follows** the marker — the scene-open prose itself uses the
player's mode for density, sensory channels, and detail. The marker is the same;
what comes after wears whichever mode the players prefer.
